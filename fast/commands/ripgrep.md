# rg (ripgrep) 速查

## 正则 vs 字面匹配

`rg` 默认正则模式，`()` `.` `|` `+` `*` 等是特殊字符。用 `-F` 关闭正则做字面搜索：

```bash
rg -F "func()" file.txt          # 精确匹配 func()
rg -F -c "error" --glob '**/*.jsonl' <path>  # 统计匹配行数
```

## 常用选项

| 选项 | 作用 |
|------|------|
| `-F` | 字面匹配，关闭正则 |
| `-c` | 统计每个文件匹配行数 |
| `-l` | 只输出匹配的文件名 |
| `-n` | 显示行号（默认开启） |
| `-i` | 忽略大小写 |
| `-w` | 全词匹配 |
| `--glob` | 文件过滤，如 `'**/*.jsonl'` |
| `--type` | 按语言过滤，如 `--type py` |

## 注意

- `--glob` 参数必须加引号，否则 shell 展开通配符
- 必须显式指定搜索路径参数，否则只搜当前目录
- `--` 分隔选项和搜索模式，避免模式被解析为选项
